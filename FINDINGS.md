# What raw Synthea output contained (measured 3 Oct 2026)

Scope: one Synthea run, Massachusetts, seed 42, `-p 50` (56 records incl. 6 deceased), reference
date 2026-10-03, Synthea master-branch-latest jar downloaded 3 Oct 2026. Unit stated per line.
Every number below is regenerated by the command named next to it.

1. **Real facility NPIs.** In the CSV export, 158 of 160 distinct organization NPIs are registered
   in NPPES, matching the real facility (unit: distinct NPI). Practitioner NPIs are all 9999-prefixed
   and unregistered (0 of 160). The FHIR export leaves organization NPIs out.
   `python3 scripts/check_npis.py out/synthea/csv`
2. **Real facility contact details in FHIR.** 480 phone values on Organization, Location and
   PractitionerRole have a real-number format (unit: telecom value), next to real facility names
   and street addresses. After `scrub`: 0. `python3 -m lab.safety <folder>`
3. **US Core 6.1.0.** 3 patient bundles: 2,412 validator errors from 6 message patterns, all traced
   to two Synthea-only Patient extensions (DALY, QALY) that make each Patient fail US Core, which
   then fails every reference to it. After `scrub`: 0 errors. Terminology checks were off, so codes
   were not validated. `scripts/validate_us_core.sh <folder> <out> 3` (rerun gave the same result).
4. **Names.** 56 of 56 patients have digits in their names (for example `Dian810`), also inside all
   3,147 clinical notes (Synthea stores each note twice; 6,294 attachments). After `scrub`: 0 and 0.
5. **Placeholder ZIP.** 10 of 56 patients have postal code `00000`. Not changed by this lab.
6. **Server leniency.** HAPI FHIR 8.12.0, default settings: rejected a dangling reference, stored an
   Observation time without a time zone (HTTP 200), which FHIR R4 does not allow.
7. **Pipeline run** (`lab.pipeline`, 50 patients, rate 0.1): 58 bundles loaded, 0 rejected; server
   counts equal manifest counts for patients (58), local lab codes (994) and pound weights (68);
   56 ADT^A04 and 1,008 ORU^R01 messages; about 90 s end to end.

Not checked: whether Synthea street addresses coincide with real residences; ValueSet bindings;
other states or larger populations; whether real interface engines accept the v2 output.
